# FantasyLane

Windows builds of FantasyLane, a 3v3 war-MOBA prototype. This repository holds
finished builds only.

**To play:** open [the latest release](../../releases/latest), download the
`FantasyLane-…-windows.zip`, unzip it into a folder you own (Documents or
Desktop), and run `FantasyLane.exe`. Nothing else needs installing.

The game checks this page for a newer version from its main menu and can update
itself.

Game art includes licensed assets by Synty Studios, distributed only as part of
the built game.
